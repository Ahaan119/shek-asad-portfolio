The complaint

Each hotel had a static one-page landing page with minimal content and no booking logic.

Diagnosis

  • Guests couldn't book directly, so direct revenue was capped.
  • No loyalty, agent or corporate paths existed.

Work done

  • Unified booking engine with real-time two-way sync to the hotel PMS (Ezee).
  • Portals for corporates, agents and loyalty members, with a points system and day-use inventory.
  • A custom CMS so the team could manage pricing, rooms and content independently.
